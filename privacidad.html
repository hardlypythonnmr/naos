Política de privacidad de NAOS

Última actualización: 11 de octubre de 2026.

NAOS usa una aplicación interna conectada a la API de YouTube solo para administrar el canal propio de NAOS: subir y programar videos, poner miniaturas y leer las estadísticas del canal. La aplicación la usa únicamente el dueño del canal.

Qué datos usa

Solo datos del canal de NAOS que entrega YouTube: videos, metadatos y estadísticas agregadas (vistas, tiempo de visualización, retención, países). No recoge datos personales de espectadores ni de terceros, no usa cookies y no vende ni comparte datos con nadie.

Cómo se guardan

Las credenciales se guardan como secretos del entorno de trabajo y nunca en código público. Los datos de la API se guardan solo el tiempo que permiten las políticas para desarrolladores de YouTube y se borran o actualizan a los 30 días.

Servicios de terceros

Esta aplicación usa los servicios de la API de YouTube. Al usarla se aplican los Términos de servicio de YouTube y la Política de privacidad de Google. El acceso se puede revocar en cualquier momento en la configuración de seguridad de Google.
